# Facial Emotion Recognition

A CNN based Facial Emotion Recognition web application built using:

- TensorFlow
- Streamlit
- CNN

## Supported Emotions

- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise

## Model Performance

Validation Accuracy: 62.8%

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
